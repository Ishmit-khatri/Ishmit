Things I've built

Multi-site WAN network design

Designed a network for a client with offices in Sydney, Melbourne and Brisbane — built the IP addressing and subnetting scheme for each site, configured WAN links between them, and built the full topology in Packet Tracer. Verified connectivity by capturing and analysing ICMP traffic in Wireshark.

IP addressingWAN linksWiresharkPacket Tracer

Virtual security lab

Built a 3-machine lab in VMware — Kali Linux, a Windows 11 target, and an OWASP Broken Web Apps VM — on an isolated network. Enabled IP forwarding and stood up an Apache server on Kali, then used Wireshark and ARP table analysis to watch how traffic actually moved between the machines.

VMwareKali LinuxWiresharkOWASP

IPv6 tunnelling & dual-stack routing

Configured IPv6 tunnels and routing between three sites, verified OSPF and EIGRP neighbour relationships, and confirmed DHCPv6/SLAAC was correctly assigning addresses — with full router and switch configuration evidence captured along the way.

IPv6OSPF / EIGRPDHCPv6

Segmented enterprise network & firewall design

Planned a VLAN structure separating public, DMZ, internal server and user traffic, added a management VLAN and a black hole VLAN for unused ports, and designed the addressing and ASA firewall placement to protect a multi-site network.

VLANsASA firewallDMZ design

Network threats & mitigation research

Researched real-world attacks including WannaCry, SQL Slammer and the Cisco IOS XE vulnerability, broke down how WannaCry actually spread, and mapped out vulnerability tools (Nmap, Nessus, OpenVAS, Wireshark) against practical mitigations — firewalls, IDS/IPS, network segmentation and MFA.

Threat researchNmapIDS/IPS

Data safety & privacy risk assessment

Group project assessing an education provider's critical information assets — student records, LMS, financial and research data — against risks like ransomware, insider threats and phishing, and mapping recommendations to New Zealand's Privacy Act 2020.

Risk assessmentPrivacy Act 2020Group project
